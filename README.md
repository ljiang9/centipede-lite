# centipede-lite 🐛

极简蜈蚣射击小游戏：致敬街机 Centipede 的核心机制——蜈蚣节被击中变成蘑菇并把蜈蚣劈成两段，撞到蘑菇或墙壁就转向下降一行；跳蚤会随机出现、留下蘑菇轨迹。

纯 Python 标准库（`argparse` / `sys` / `random`），无依赖。

## 运行

```bash
python3 -m centipede_lite              # 交互游玩（需要终端）
python3 -m centipede_lite --auto --frames 600 --seed 42   # 无头自动演示
```

## 操作

每行输入一个命令，回车执行一帧：

| 命令 | 动作 |
|------|------|
| a / d | 左 / 右移 |
| w / s | 上 / 下移（限底部 4 行） |
| f | 开火 |
| q | 退出 |

## 计分

| 目标 | 分数 |
|------|------|
| 蜈蚣头 | 100 |
| 蜈蚣节 | 10 |
| 跳蚤（2 枪） | 200 |
| 蘑菇 | 1 |

## 图例

- `H` 蜈蚣头，`o` 蜈蚣节，`m` 蘑菇，`F` 跳蚤，`┃` 子弹，`A` 你
- 3 条命，清掉一整条蜈蚣进入下一波

## 限制

- 回合制文本交互，**无实时键盘输入**（无 curses/pygame 依赖是故意的，保持零依赖）。
- 蜘蛛、毒蘑菇等原版机制未实现；跳蚤只有一种行为模式。
